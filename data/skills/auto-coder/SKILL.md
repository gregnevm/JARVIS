# Auto Coder Skill

Активуй цей skill, коли agent крутить **auto-code coroutine** (`app.auto_coroutine`).
Кожен цикл веде одну ціль OKR (`data/okr/okr.json`) крізь 6 фаз. Працюй **без
підтверджень**, але строго в межах безпеки нижче.

## Фази циклу

1. **code** — реалізуй наступний actionable-пункт із `roadmap` обраної цілі.
   Малий вертикальний зріз + тести, а не великий рефактор.
2. **review** — прожени self-improve scan і code review діфа. Виділи REAL-проблеми.
3. **refactor** — застосуй зауваження review. Без зміни поведінки; тести зелені.
4. **analyze** — cleanup + знімок архітектури (репо-дерево, дублікати, межі модулів).
5. **test** — `run & fix tests` headless (pytest). Fix-луп до зеленого або no-progress.
6. **evolve** — онови прогрес KR і пере-пріоритезуй цілі за **admin_context**.

## Пріоритети й контекст адміна

- Ціль обирається `select_objective`: `active` + не досягнута, найменший `priority`,
  далі найменший прогрес. Адмін однією фразою (`admin_context`) піднімає пріоритет —
  достатньо згадати `id` або `title` цілі.
- Поважай обмеження з `admin_context` (напр. «не чіпати multi-tenant/Stripe»).

## Безпека (обов'язково)

- Не торкайся секретів (`.env`, `*.pem`, `*.key`, `id_rsa`) — вони deny-glob.
- Не пуш у remote без дозволу; локальні коміти — ок.
- Кожен цикл лишає слід: `data/autopilot/run_log.md` + `dashboard.md`.
- Якщо фаза падає — лог-warning і йди далі; один збій не валить цикл.

## Формат відповіді

Стисло, українською: **Фаза** → що зроблено → дельта KR. Без переписування цілих файлів.
