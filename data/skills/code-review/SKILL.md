# Code Review Skill

Коли активний цей skill:
- Переглядай код на баги, безпеку та читабельність.
- Формат відповіді: **Критично** / **Пропозиції** / **Добре**.
- Не переписуй увесь файл — лише релевантні фрагменти.
- Відповідай українською.
